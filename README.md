# gzh-download-knowledge · 公众号文章下载归档

把自己的公众号历史文章**批量保存成本地 Markdown**，方便个人归档、做知识库。

一句话：以前得一条条手动复制、保存网页，现在用 AI 批量干完——不用装任何插件、不用填任何 token/cookie。

## 能干什么

- 打开公众号后台「发表记录」（官方全量列表），从最新一篇开始批量下载
- 每篇存成一个 Markdown，带标题、公众号名、原文链接、发表日期
- 自动跳过已下载过的文章，重复跑不会重复存
- **纯本地运行**：文章只落到你自己电脑上，不上传任何内容

## 前提（必须装）

- **必须装 webclaw3**：本 skill 靠 webclaw3 打开你已登录的公众号后台，不装跑不了。
  - 装好后先检查一遍通道：`node <webclaw3安装路径>/scripts/webclaw3.mjs doctor`
  - 路径一般在 `~/.claude/skills/webclaw3` 或 `~/.workbuddy/skills/webclaw3`
- 浏览器里先登录好公众号后台（`mp.weixin.qq.com`）——登录的是哪个号，就归档哪个号。

## 怎么用

```bash
node skill.mjs <input.json>
```

核心参数就三个：

| 参数 | 说明 | 默认 |
|---|---|---|
| `count` | 这次要新增下载几篇 | 10 |
| `offset` | 跳过前 N 篇再取（增量归档：第一次 0，第二次 10…） | 0 |
| `outputDir` | 存到哪里 | `./gzh-export/` |

完整参数见 SKILL.md。

## 结果长这样

`outputDir/` 下：

- `articles/`：每篇一个 `.md`（文件名：序号-标题前20字）
- `index.json`：本次下载清单（几篇、每篇标题/链接/状态）

## 常见问题

- **报「浏览器中继服务不可用」**：webclaw3 没装或没启动，按上面「前提」装好、跑通 doctor 再试。
- **报「浏览器未登录公众号后台」**：在浏览器打开 `mp.weixin.qq.com` 扫码登录后重跑。
- **下载中断 / 缺了几篇**：直接重跑即可——已下载的会自动跳过，接着把缺口补齐。

## 边界

只归档**自己的公众号**（后台登录的那个号）。不做"抓别人的文章"——既违规又有版权风险，这也是这个 skill 刻意不做的事。
